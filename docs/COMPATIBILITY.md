# 谱面格式与非官方壳子扩展

## 当前 1.0.10 的边界

编辑器默认处理既有 In Falsus 谱面语义，同时尽量保存未识别内容。保留未知记录不等于支持播放其语义。当前源码没有 `timinggroup` 功能，也没有可供开启的 timinggroup 兼容模式。

社区修改本体后增加的 `timinggroup` 是**非官方壳子扩展**，不能描述成原游戏已支持的参数。编辑器核心仍未实现它；可选的 Visual & UI 1.0.39 插件在编辑器侧提供有限支持，见下文。后续新增或修改这类功能时，必须遵循 [CONTRIBUTING.md](../CONTRIBUTING.md) 的标题、正文与公告标记要求。

## Visual & UI 插件扩展（1.0.39）

插件源码和三个默认外置工具见 [Mods/VisualUI/1.0.39](../Mods/VisualUI/1.0.39/README.md)。这是安装到 InFalsus Studio Windows Mono 1.0.10 的可选 BepInEx 插件；未安装插件的原版编辑器不获得这些编辑语义。安装后，插件识别扩展语句并提供编辑 UI，不会在打开时自动迁移谱面。具体目标游戏壳子版本、语法及限制以该插件的[兼容性说明](../Mods/VisualUI/1.0.39/COMPATIBILITY.md)为准。

插件支持保存/另存为保留扩展文本；它没有提供到官方格式的转换或静默移除流程。官方游戏没有这些时间组语义，不能据此推断官方格式可播放。插件在编辑器侧的格式/行为验证不等于目标壳子的判定或游玩验证；后者在 1.0.39 中未验证。

## SkyArea groupid

`groupid` 是 SkyArea 可选的最后一个参数，关联 Sky 的分组/头框规则，不能代替独立时间组。

不指定组的当前作者输出：

```text
skyarea(157753,50,100,10,76,119,86,0,0,21)
```

手动指定非负组号（例如 3）：

```text
skyarea(157753,50,100,10,76,119,86,0,0,21,3)
```

- 新建、续接、切分、默认粘贴不写 groupid；“Sky 自动分组”才显式赋从 0 开始的 ID，支持一次撤销。
- 旧 `-1` 兼容读取，表示未指定组；不能再次把默认作者输出改成写入 `-1`。打开旧工作谱不会自动迁移。
- 未指定/旧 -1 的自动头框连接使用首尾 ±2ms 和横向接触；非负组保留组内首条规则。
- 参数清空及“全部不指定组”工具清除赋值；非标准尾字段需保留原文证据，不能因删除参数而移位成另一个组号。

## 为非官方扩展准备的开发约定

以下是未来扩展必须满足的约定，不是当前已交付能力：

1. 使用清楚命名、用户显式启用的壳子能力/兼容模式，默认官方语义不变。不能仅凭一条未知记录悄悄切换解释器。
2. 给出可定位的目标壳子版本与格式说明，记录语句作用域、参数单位、默认值、时间/BPM/滚速处理和与现有语义的交互。
3. 扩展数据必须可保存、撤销与重新打开；保留未知/原始 token 规则。涉及分组的引用不能复用 SkyArea groupid 偷换概念。
4. 导出官方格式时明确检测扩展。选择阻止导出、用户显式选择且可说明等价性的转换，或经确认的有损导出；禁止静默丢失语义。
5. 明确列出壳子功能验证、官方模式回归，以及未验证项。提交、PR、功能说明与公告都标记 `[非官方壳子]`。

最小复现应能看出官方与扩展模式的差异。不要在公共文档中把某个修改版游戏的行为写成所有 In Falsus 版本的保证。

## 其他格式约束

- 时间和空间份数不是同一概念。Sky/Flick 的 X、份数、宽度用整数表达比值；128 上限针对采样切分/续接及显式压缩，不能在读取时强制全谱重编码。
- 音频偏移关系为 `audioTime = chartTime + offset`。
- 默认保存是显式 Save / Ctrl+S；输入确认只更改内存草稿。已识别时间语句只在显式保存/导出时排序，保持同刻运行时优先级与源内容。
- 检查 Tap 的横向重叠及时间差 <3ms、Hold 的轨道与时间交集、Flick 全参数重复、Hold/Sky 时长 <5ms；不把任意 Sky 相交当作叠键。
