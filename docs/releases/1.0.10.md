# In Falsus Studio 1.0.10 更新公告

发布基线：2026-10-05，**包含同版本 Flick 尾部修正版**。2026-10-13 将该源码状态整理到 GitHub，应用版本不变。

## 1.0.10

- **Sky 连接更宽容**：首尾相隔或重叠 2ms 以内可连接，仍检查横向接触，不修改谱面时间。
- **新增短音符检查**：持续时间小于 5ms 的 Hold/Sky 会在谱面检查中提示，可跳转并选中。
- **保存自动按时间排序**：已识别时间语句在 Save/导出时稳定排序，同刻顺序、注释和未知内容保留。
- **新增 Sky 自动分组**：在“工具”中按时间与连接关系为当前谱面分配 groupid，可整次撤销。新建 Sky 仍默认不指定组。
- **优化 Flick 形态与尾部**：不同宽度保持一致的头部尺度，宽 Flick 的细尾延伸到真正端点，修复最后四分之一提前消失。

## 1.0.9

- 歌曲信息可编辑原版预览片段开始/结束秒数，以及当前难度曲绘画师。
- 主音乐文件失效时重新查找 MP3/OGG，已有工作谱保留。
- 每次打开重查曲绘，一张自动使用，多张变化时重新选择；未变时记住成功选择，同名替换也重新加载。
- Sky 默认省略最后 groupid 参数；清组工具改为“全部不指定组”，仍可手动填非负组号。
- 元数据与资源路径先进入草稿，Save 后写盘。

## 1.0.8

- Sky 切分、Flick 输出和续接的横向坐标最多使用 128 份。
- 按原左右边界拟合整数比值，保留相邻切点；不改变切分时间。
- 新增大分母压缩工具，支持一次撤销和手动保存。

## 使用与兼容性

编辑完成后使用 Save / Ctrl+S；进入新版本不会自动迁移已有工作谱。构建 Windows 程序见[构建指南](../BUILDING.md)。

当前版本未加入非官方 `timinggroup`。未来所有壳子专属功能必须在提交、PR 和公告中标记 `[非官方壳子]`，注明适用版本及官方兼容性。

历史自动检查与构建结果见[验证记录](../VALIDATION.md)。本公告不将自动检查视为所有显卡、音频设备或游戏本体的实测保证。更多版本见[完整更新记录](../../CHANGELOG.md)。
